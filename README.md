
# AI-Powered College Enquiry Chatbot

## Project Overview
A college enquiry chatbot built with Python and Streamlit.

## Technologies Used
- Python
- Streamlit
- Pandas
- Scikit-learn
- TF-IDF Vectorization
- Cosine Similarity

## Features
- Answers common college FAQs
- Matches questions using NLP
- Provides fallback responses
- Maintains conversation history
- Includes a sample college FAQ dataset

## Run the Application
Install dependencies:

pip install -r requirements.txt

Start the chatbot:

streamlit run app.py

## Dataset Notice
The included FAQ dataset contains illustrative sample information. It is not verified information about a real college.
